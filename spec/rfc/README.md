# Folio RFCs

RFCs (Request for Comments) are design documents proposing changes to the Folio specification. They are numbered sequentially and live in this directory.

| Field | Rule |
|---|---|
| **Number** | Sequential, zero-padded to three digits (`RFC-001`, `RFC-002`, …). |
| **Status** | `Draft` → `Accepted` or `Rejected`. An RFC is Accepted by merge of its acceptance commit on `main`. |
| **License** | Specification documents — [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), like the rest of `spec/`. |
| **Authorship** | Every RFC names an author and contributors in its front matter. |

An RFC is a proposal, not part of the normative specification. Normative grammar resulting from an accepted RFC lands as a revision of the documents in [`spec/`](../README.md).
